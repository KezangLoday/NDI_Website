Bhutan NDI Website Redesign - Requirement Discussion Summary

Background & Objective

The primary objective of the redesign is not necessarily to modernize the visual appearance of

the website, but to improve how Bhutan NDI communicates its services and value proposition.

Current  feedback  is  that  users  need  to  scroll  through  multiple  sections before understanding

what  Bhutan  NDI does and what use cases it enables. Therefore, the redesign should focus on

making the website easier to understand at a glance, while also exploring visual improvements

where appropriate.

1.  Homepage

Overall Objective

The homepage should clearly communicate Bhutan NDI’s value proposition and key use

cases immediately upon landing, without requiring users to scroll extensively.

Key Requirements

a.  More Use-Case driven homepage

●  Shift focus from features and integrations to real-world use cases.

●  Users should quickly understand what they can do with Bhutan NDI.

b.  Integration partners section

Current issue:

●  The existing use case/integration section feels static.

Suggested direction

●  Create a horizontal scrolling or carousel section displaying partner logos

and names.

●  Separate  actual  use  cases  into  their  own  dedicated  section  rather  than

tying them directly to individual partners.

c.  Features Section

●  Existing feature section can largely remain as is.

●  Consider redesigning or modernizing the graphics and illustrations.

d.  Collaboration section

●  The section has become visually large and static.

●  White box layout feels outdated.

Requirements:

●  Update with all current international partners.

●  Explore more dynamic presentation methods.

Homepage success criteria

Users should be able to understand:

●  What Bhutan NDI is.

●  What problem it solves.

●  What services it enables.

Within the first glance or minimal scrolling.

2. Users Section

Overall objective

Present NDI’s use cases in a simple, user-friendly manner without technical jargons.

Requirements:

a.  Simplify language

●  Focus on user outcomes and benefits.

●  Clearly explain what users can do with Bhutan NDI.

b.  Use Cases

Highlight major use cases using simple language.

Examples:

●  Open a bank account online

●  Verify identity digitally

●  Access services securely online

c.  Tutorials

●  Attach tutorial videos where relevant

●  Redirect users to existing YouTube tutorials where appropriate.

●  Tutorials should be closely linked to major use cases.

d.  Bhutan NDI in Action

●  Existing section can remain.

●  Team  may  explore  redesigning  the  infographic  for  better  communication  and

visual appeal.

●  Benefits of Bhutan NDI Wallet can remain unchanged.

User section success criteria

A non-technical user should immediately understand:

●  What NDI does

●  How it benefits them

●  How they can start using it.

3. Organizations section

Overall objective

Help  organizations  understand  how  Bhutan  NDI  services  can  support  their  operational  and

business use cases.

Key requirements:

Merge organizations and value added services

Current issue:

Significant overlap between both sections & content repetition.

Content Direction

Instead of describing services in isolation:

Present:

●  Services

●  Use case

●  Organizational benefit

Current feedback:

●  Existing content contains lengthy paragraphs and feels text-heavy

●  Language is vague and difficult to scan

Goal: Organizations should quickly understand:

●  Available NDI services.

●  Potential integration opportunities

●  Business value of each service.

4. Governance Section

No content changes, government content is mandated and includes the NDI act.

Changes can be made to visual redesign, layout improvements, and improved readability.

No major content restructuring requested during discussion.

Team Discussion: whether some resources categories could be consolidated.

Potential grouping: Webinars, publications, events, blogs

Reason: Dropdown currently feels crowded, content categories may overlap.

Dashboard

Options discussed: separate section below Vision & Mission

7. Footer

●  Add whatsApp icon/link alongside existing media link

Design Principles Agreed During Discussion

Redesign should focus on:

1.  Clarity: Users should understand Bhutan NDI immediately.

2.  Use case driven communication: Focus on what users and organizations can do rather

than technical features.

3.  Simplicity: Reduce lengthy paragraphs and technical jargon.

4.  Better  information  hierarchy:  Important  services  and  use  cases  should  be  visible

without extensive scrolling.

5.  Improved  visual  presentation:  Visual  redesign  is  encouraged  where  it  supports

communication and usability.
